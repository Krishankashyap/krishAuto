# Facebook SEO & Viral Copy Skill

## Master Editorial Principles
1. **The 1-Line Hook**: Capture mobile scrolling attention within 0.8 seconds.
2. **Generous Vertical Whitespace**: Never produce dense paragraphs or walls of text. Social media users read in micro-bites.
3. **Outbound Link Reach Protection**: Never place outbound links directly in the main caption body. Facebook penalizes external links with up to a 50% reach reduction. Always recommend placing links in the **first comment**.
4. **Hashtag Restraint**: Limit to 3-6 targeted, high-relevance hashtags.
5. **Image Alt-Text**: Provide descriptive alt-text for accessibility and search indexing.
