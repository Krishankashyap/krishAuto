# Complete Android Mobile Guide — XDeepFreeVideoGeneration

Produce broadcast-quality **Vox documentaries, Crayon stickman animations, and Crime suspense explainers** directly on your Android phone using **Antigravity as the autonomous agent**.

---

## ⚡ What Makes the Mobile Edition Different?

1. **Featherlight Package (<28 MB zip vs 440 MB previously)**:
   - All duplicate audio stripped; curated 96kbps background music beds covering 6 niches.
   - Unpacks in <2 seconds in Termux with zero memory pressure.
2. **Mobile Screen Responsive (9:16 Vertical First)**:
   - Native 1080x1920 vertical format for YouTube Shorts, Instagram Reels, and TikTok.
   - Built-in **Mobile Safe Zones**: ensures labels, stamps, and graphics never get obscured by phone status bars, camera notches, or TikTok/Reels UI buttons (like, comment, share, caption marquee).
3. **Android Low Memory Killer (LMK) Protection**:
   - Clamps rendering workers to 1 (or 2) and throttles FFmpeg threads, keeping peak RAM under 150 MB and preventing Termux crashes.
   - Uses sub-millisecond phonetic syllable alignment (<0.2s, <20 MB RAM) with zero neural network dependencies.

## 🛠️ Step 1: 1-Time Android Phone Setup

### 1. Install Termux
Download and install [Termux](https://github.com/termux/termux-app/releases) (or via F-Droid).

### 2. Extract the Zip Archive
Place `xdeepfreevideogeneration_mobile.zip` in your phone's storage and extract it in Termux:
```bash
termux-setup-storage
cd ~/storage/shared/Download
unzip xdeepfreevideogeneration_mobile.zip -d xdeep_mobile
cd xdeep_mobile
```

### 3. Run Automated Mobile Installer
```bash
sh setup_mobile.sh
```
This automatically installs `ffmpeg`, `python3`, `pillow`, `numpy`, and verifies the engine.

## 🤖 Step 2: Using Antigravity as the Agent on Mobile

When chatting with Antigravity on your phone (via web or CLI):

1. **DeepX Flow Bridge Connection**:
   - The DeepX Flow Bridge connects directly via WebSocket (`ws://127.0.0.1:8792/ws`).
   - Open [flow.google.com](https://flow.google.com) in your browser with the extension active.
   - Antigravity automatically detects the active canvas and uploads references in-memory without manual switching.
2. **Tell Antigravity Your Video Idea**:
   Simply prompt Antigravity:
   > *"Make a 45-second 9:16 mobile explainer about the Mystery of the Bermuda Triangle in Hindi/English using Vox documentary style."*
3. **Autopilot Execution**:
   - Antigravity writes the script and generates voiceover in ~1s via Cartesia TTS.
   - Aligns words with 0ms gap accuracy via `core/align.py`.
   - Generates transparent cutouts on Google Flow (`Banana Nano 2.1` on `#FF00FF`).
   - Executes `python3 mobile_run.py` to produce your final `master.mp4`.

## 🎬 Step 3: Turnkey 1-Command CLI Workflow

If you prefer running commands manually in Termux:

```bash
# 1. Align your voiceover to script
python3 mobile_run.py --align-only

# 2. Mix ducked broadcast audio (SFX + loopable music bed)
python3 mobile_run.py --mix-only

# 3. Render master 9:16 video
python3 mobile_run.py --render-only

# Or run the ENTIRE pipeline in one go:
python3 mobile_run.py
```

### Previewing the Video on Your Phone
```bash
termux-open master.mp4
```
This immediately opens `master.mp4` in your Android phone's default video player or gallery.

## 📐 Mobile Safe-Zone Reference (1080x1920)

| Region | Margin | Reason |
|---|---|---|
| **Top** | `160px` | Phone camera notch, status bar, and search header |
| **Bottom** | `300px` | TikTok/Reels caption text, creator handle, and audio marquee |
| **Right** | `130px` | Like, comment, share, and bookmark button rail |
| **Left** | `40px` | Edge safety padding |

All labels, badges (`KEY`, `PIN`, `LBL`), forensic stamps, and visuals generated by `render.py` automatically stay inside this safe zone.
