# Hand-Drawn Doodle & Sketchbook Style

## Visual Language
- **Canvas Texture**: Warm textured sketchbook paper (`#FAF7EE`), subtle binder ring holes, lined notebook grids.
- **Graphic Annotations**: Pastel yellow/blue highlighter sweeps, hand-drawn wobbly arrows, doodle circles around key words, sticky notes, and felt-tip marker notes.
